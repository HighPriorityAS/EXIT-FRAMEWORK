# EXIT Copy System v2

## Category
**EXIT is an open protocol for human autonomy under load.**

Brand line:
**Strategic control. Human freedom.**

Core equation:
**CHAOS → CONVICTION → CONTROL**

Founder line:
**The protocol is open. The origin is finite.**

## Canonical operating language
- SYSTEM > MOTIVATION
- State before story
- Signal before interpretation
- Stabilize before you optimize
- Shrink the control surface
- Find the active constraint
- One bounded move
- Action → evidence → adjustment
- Re-entry beats restart
- Recovery restores operating capacity
- Control is the ability to choose

## Strategic copy rules
1. Define the category before explaining features.
2. Prefer operational language to motivational language.
3. Use EXIT terms consistently; do not invent parallel models unless they add a distinct function.
4. Capacity is variable. The system should compress before it demands more force.
5. The public core is not framed as a free tier. It is the protocol.
6. Founder 100 is identity, belonging, provenance, participation and permanent scarcity — never premium access.
7. Research, lived experience, product language and scientific evidence remain distinguishable.
8. Functional tool copy prioritizes clarity over brand poetry.

## Avoid
- "paid core"
- "premium access"
- "membership" for Control Room
- "complete Exit OS" as a gated product
- generic self-help claims
- artificial urgency
- multiple competing high-level models

## Founder 100
Hard rule: **100 positions. One origin. Never expanded.**
The system may scale. The founding cohort does not.
