# EXIT Language v1.0

Public operational vocabulary for human autonomy under load.

## Core equation
CHAOS → CONVICTION → CONTROL

- Chaos: unresolved signals, demands, loops, or constraints competing for limited capacity.
- Conviction: sufficient clarity to choose a direction without pretending uncertainty has disappeared.
- Control: the practical ability to choose and execute the next useful action, then update from evidence.

## Canonical principles
- SYSTEM > MOTIVATION
- State before story
- Signal before interpretation
- Stabilize before you optimize
- Re-entry beats restart
- Recovery restores operating capacity
- Control is the ability to choose

1. Stabilize
2. Observe
3. Separate
4. Choose
5. Execute
6. Measure
7. Document
8. Adjust

EXIT Language is an operational vocabulary, not a clinical taxonomy, diagnosis system, or claim of scientific validation.

Public by design.
