# Exit Framework V8

Static, responsive site for **Exit Framework — Chaos to Control**.

## Release scope

- Responsive 16:9 and 9:16 premium hero artwork
- Deterministic 18-second vortex loop with reduced-motion support
- Recovery-first framework, philosophy, applications and ecosystem copy
- Three open-access field notes
- One canonical GitHub Pages workflow
- Custom domain: `theexitmission.com`

## Local preview

Serve the repository root with any static HTTP server. Opening files directly can hide routing and asset-path problems.

## Deployment

Every push to `main` runs `.github/workflows/deploy-pages.yml`. The workflow validates required assets, the custom domain and canonical “Chaos to Control” copy before deployment.
