Privacy / Local first

Data should have a job.

EXIT Core is public and local-first. Payment data is not required to use the protocol, Sprint or Control Room.

Where does Sprint and Control Room data live?

Signed out, operating state is stored in browser-local storage on that device.

What changes if I use Account + Sync?

Account is optional. If you sign in, EXIT keeps a private synchronized copy of the operating state so it can be restored across devices. Local use remains available without an account.

What can the synchronized state contain?

Sprint progress, check-ins, ratings, priorities, active friction, reviews and the Control System you create. The sign-in service also processes the email address used for authentication.

Can I delete the cloud copy?

Yes. An authenticated user can delete the synchronized EXIT state from Account + Sync. Browser-local data on the current device is separate.

Does EXIT Core require payment data?

No. The public protocol, Sprint and Control Room do not require payment.

What happens if I join the Founder 100 launch list?

The current interest link goes to the EXIT Substack list. Subscribing there is a separate action governed by that service's terms and privacy information.

Is product data research data?

No. EXIT product use and Human Autonomy Study are separate. Using EXIT or holding Founder status is not research consent.

Boundary

Research has its own process.

Study recruitment, consent and research data collection belong to Human Autonomy Study, not the public EXIT product surface.

Research participation is not sold.

Founder status and product use do not create study eligibility or consent.
